# Homebrew tap for agent-auth-cli

Homebrew formula for [`agent-auth-cli`](https://github.com/Kong/agent-auth-cli),
a one-shot OIDC credential helper for local coding agents.

The formula here is generated by GoReleaser on every `agent-auth-cli` release
tag. Do not edit `Formula/agent-auth-cli.rb` by hand.

## Install

`agent-auth-cli` and its release assets are internal while the tool is
internal, so Homebrew needs a GitHub token with `repo` scope from the
[settings panel](https://github.com/settings/tokens) to read both this tap and
the release archives:

```sh
export HOMEBREW_GITHUB_API_TOKEN=<YOUR TOKEN>
brew tap Kong/agent-auth-cli git@github.com:Kong/homebrew-agent-auth-cli.git
brew install Kong/agent-auth-cli/agent-auth-cli
```

Use `https://github.com/Kong/homebrew-agent-auth-cli.git` instead if your local
git does not reach GitHub over SSH.

## Going public

Both this tap and `Kong/agent-auth-cli` are internal for now. When the tool is
published, the token requirement and `Formula/lib/private_strategy.rb` go away:
drop `download_strategy` and `custom_require` from the `brews` block in
`Kong/agent-auth-cli`'s `.goreleaser.yaml`, and `brew tap Kong/agent-auth-cli`
works with no token.
