# Homebrew tap for kong-harnesses

Homebrew formula for [`kong-harnesses`](https://github.com/Kong/kong-harnesses),
a one-shot OIDC credential helper for local coding agents.

The formula here is generated by GoReleaser on every `kong-harnesses` release
tag. Do not edit `Formula/kong-harnesses.rb` by hand.

## Install

`kong-harnesses` and its release assets are internal while the tool is
internal, so Homebrew needs a GitHub token with `repo` scope from the
[settings panel](https://github.com/settings/tokens) to read both this tap and
the release archives:

```sh
export HOMEBREW_GITHUB_API_TOKEN=<YOUR TOKEN>
brew trust --tap kong/kong-harnesses
brew tap Kong/kong-harnesses git@github.com:Kong/homebrew-kong-harnesses.git
brew install Kong/kong-harnesses/kong-harnesses
```

Use `https://github.com/Kong/homebrew-kong-harnesses.git` instead if your local
git does not reach GitHub over SSH.

## Upgrading from agent-auth-cli

The tool was called `agent-auth-cli`, and this tap was
`Kong/homebrew-agent-auth-cli`. A tap added as `kong/agent-auth-cli` keeps
working, because GitHub sends the old address to this repository.
`formula_renames.json` maps the old formula name to `kong-harnesses`, so
`brew update` and `brew upgrade` move an `agent-auth-cli` install to the new
formula, and `brew install agent-auth-cli` installs `kong-harnesses`. From
v0.9.0 the formula also installs `agent-auth-cli` as a link to
`kong-harnesses`, so client settings that an older release wrote keep working.

Keep the name `homebrew-agent-auth-cli` free in the Kong organization: a new
repository with that name would end the redirect.

## Going public

Both this tap and `Kong/kong-harnesses` are internal for now. When the tool is
published, the token requirement and `lib/private_strategy.rb` go away:
drop `download_strategy` and `custom_require` from the `brews` block in
`Kong/kong-harnesses`'s `.goreleaser.yaml`, and `brew tap Kong/kong-harnesses`
works with no token.
